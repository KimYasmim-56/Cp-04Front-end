# EcoTrend — E-commerce sustentável

Projeto acadêmico de Front-end usando:
- HTML5
- CSS3
- Bootstrap 5.3
- Font Awesome 7 (ícones)
- Google Fonts (Poppins)
- JavaScript
- LocalStorage

## Como abrir
Abra `index.html` no navegador.

## Funcionalidades
- Home responsiva
- Catálogo com Grid Bootstrap
- Busca e filtros
- Página individual de produto
- Carrinho com quantidade e subtotal
- Finalização de compra simulada
- Toasts de interação
- Favoritos
- Modo escuro
- Formulário de contato
- Páginas Sobre, Produtos e Carrinho

As imagens são carregadas de URLs externas, então é necessário estar conectado à internet para visualizá-las.
